# Slikk Home Decor Launch Strategy

Interactive marketing launch case study built for the Builder's League.

## Problem

The case study defines how a home-decor brand can identify its ideal customer,
position a launch, compare competitors, and turn strategy into an actionable
campaign.

## How It Works

The project packages the complete launch strategy into a responsive,
single-page presentation with navigation, audience profiles, market analysis,
campaign recommendations, and supporting metrics.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Vercel

making it easy to deploy, share, and present.
